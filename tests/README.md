# 🧪 HealVPN Test System & Verification Suite

Этот каталог содержит автоматизированные тесты для проверки целостности базы данных, фоновых задач, платежной системы и интеграции с панелью Marzban.

---

## 📂 Структура тестовых сценариев

В проекте реализованы три основных тестовых сценария:

1. **[test_payment_system.py](file:///Users/aleksandrposokhov/Life/HealVPN/tests/test_payment_system.py)** (в каталоге tests/):
   - **Описание:** Локальный тестовый набор из **28 тестов**. Полностью имитирует транзакции базы данных SQLite, гонки, таймауты, кэширование, поведение YooKassa и фоновые задачи `APScheduler`.
   - **Покрытие:**
     - Состояние гонки (параллельные ручные/фоновые клики).
     - Идемпотентность и исключение двойных списаний.
     - Корректность вычисления дат и продления подписок.
     - Логика автопродления и лимита ошибок платежей (Failed Payments Lifecycle: 24h ➡️ 12h ➡️ 30m ➡️ выключение).
     - Бесшумное логирование 404.
     - Инвалидация кэша подписок `sub_cache`.

2. **[test_subscription_persistence.py](file:///Users/aleksandrposokhov/Life/HealVPN/tests/test_subscription_persistence.py)**:
   - **Описание:** Проверка преемственности подписок в Marzban (продление без сброса и изменения ссылки).
   - **Назначение:** Быстрый тест на сохранение токена подписки при увеличении срока действия.

3. **[test_marzban_integration_live.py](file:///Users/aleksandrposokhov/Life/HealVPN/tests/test_marzban_integration_live.py)**:
   - **Описание:** Комплексный сквозной интеграционный тест (Live E2E), который напрямую общается с **настоящим Marzban API** (использует параметры из `.env`).
   - **Покрытие:**
     - Подключение и авторизация на панели.
     - Создание нового пользователя и установка исходного срока действия.
     - Извлечение токена из возвращенной ссылки подписки.
     - Продление срока действия подписки на 30 дней и проверка корректности Unix timestamp.
     - Полное совпадение токена и ссылки до и после продления.
     - Авто-преемственность токена при вызове без передачи `forced_token`.
     - Бесшумный возврат `None` при 404 и удаление пользователя после теста.

---

## 🚀 Запуск тестов

Вы можете запустить каждый из тестов напрямую из консоли проекта:

### 1. Запуск полной локальной симуляции (28 тестов)
```bash
python3 tests/test_payment_system.py
```

### 2. Запуск живых интеграционных тестов с панелью Marzban
```bash
python3 tests/test_marzban_integration_live.py
```

### 3. Запуск базового теста преемственности ссылок
```bash
python3 tests/test_subscription_persistence.py
```
