# 🛡️ HealVPN Bot
Этот репозиторий содержит исходный код Telegram-бота для управления VPN-сервисом HealVPN.
Файлы были скопированы из ветки `WrongKeyFix` основного репозитория.

### Содержимое:
- `run_bot.py`: Главный файл запуска бота.
- `database.py`: Логика работы с базой данных (Supabase).
- `handlers.py`: Обработчики команд и сообщений.
- `keyboards.py`: Определение инлайн-клавиатур.
- `marzban_api.py`: Интеграция с API Marzban.
- `scheduler.py`: Планировщик задач (проверка подписок).
- `config.py`: Загрузка конфигурации из `.env`.
- `models.py`: Модели данных.
- `style.css`, `index.html`, `script.js`: Веб-интерфейс (предположительно для лендинга или админки).
- `assets/`: Статические файлы (логотипы и т.д.).
- `DEPLOYMENT_GUIDE.md`: Инструкция по развертыванию.
- `HealVPN_CONTEXT.md`: Контекст и стратегия развития проекта.

### Настройка:
1. Убедитесь, что файл `.env` заполнен корректными данными (токен бота, ключи API, данные БД).
2. Установите зависимости: `pip install -r requirements.txt`.
3. Запустите бота: `python run_bot.py`.
