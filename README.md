# 🛡️ Проект VPN (VPN Project)

Эта папка содержит рабочие файлы, скрипты и техническую документацию по вашему собственному VPN-сервису.
Здесь хранятся данные о серверах, настройках протоколов (например, VLESS/Xray, WireGuard), списке клиентов и планах по развитию сервиса. 

Подробный контекст, архитектура проекта и стратегия развития описаны в файле `Vpn_project_CONTEXT.md`.
