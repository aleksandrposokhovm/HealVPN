# 🛡️ HealVPN Bot

Этот репозиторий содержит исходный код Telegram-бота для управления VPN-сервисом HealVPN. Бот построен на базе **Aiogram 3.x** и интегрирован с панелью **Marzban** и платежной системой **YooKassa**.

## 🚀 Основные возможности

- **Пробный период**: 7 дней доступа за 11₽ (доступно раз в 3 месяца).
- **Подписка**: Автоматическое продление за 88₽/месяц.
- **Умные уведомления**: 
  - Первая попытка списания и уведомление за 24 часа.
  - Повторная попытка и уведомление за 12 часов.
  - Финальное уведомление за 30 минут до отключения.
- **Отказоустойчивость**: 
  - Три попытки автопродления до момента фактического истечения срока.
  - Автоматическое уведомление пользователя о проблемах с картой.
- **Реактивация**: Уведомление пользователей о возможности повторного использования пробного периода через 90 дней.

## 📂 Структура проекта

Логика бота вынесена в отдельный пакет `bot/` для чистоты архитектуры:

- `run_bot.py`: Главная точка входа для запуска бота.
- `bot/`:
  - `handlers.py`: Обработка команд и платежных callback-ов.
  - `keyboards.py`: Меню и кнопки.
  - `database.py`: Работа с SQLAlchemy и кэширование подписок.
  - `scheduler.py`: Планировщик фоновых задач (автопродление, рассылки).
  - `marzban_api.py`: Интеграция с API VPN-панели.
  - `config.py`: Конфигурация через Pydantic Settings.
  - `models.py`: Схемы таблиц базы данных.
  - `assets/`: Логотипы и медиа-файлы.
- `requirements.txt`: Список всех зависимостей.
- `.env`: Файл конфигурации (необходимо создать на основе примера).

## 🛠 Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/aleksandrposokhovm/HealVPN.git
   cd HealVPN
   ```

2. **Настройте окружение**:
   Создайте файл `.env` в корне проекта и заполните его:
   ```env
   BOT_TOKEN=ваш_токен
   YOOKASSA_SHOP_ID=ваш_id
   YOOKASSA_SECRET_KEY=ваш_ключ
   VPN_API_URL=https://ваша_панель:8000
   MARZBAN_ADMIN_USERNAME=admin
   MARZBAN_ADMIN_PASSWORD=password
   DATABASE_URL=postgresql+asyncpg://user:pass@host:port/db
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите бота**:
   ```bash
   python run_bot.py
   ```
